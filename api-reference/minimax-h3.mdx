MiniMax H3 适合短视频创作、首尾帧过渡和多素材参考生成。API 模型名为 `minimax-video-h3`，支持文本、首尾帧和图片／视频／音频参考。

AI 可读取[本页 Markdown](https://docs.ziy.cc/api-reference/minimax-h3.md)；其他模型见 [llms.txt](https://docs.ziy.cc/llms.txt)。

| 项目 | 约定 |
|------|------|
| 根地址 | `https://llm.ziy.cc` |
| 鉴权 | `Authorization: Bearer sk-你的密钥` |
| 请求类型 | `Content-Type: application/json` |
| 默认输出 | 5 秒、768P、无水印；纯文本默认 16:9 |
| 输出范围 | 整数 4–15 秒，768P 或 2K |

使用 KUNPO API Key。开启模型限制的密钥须放行 `minimax-video-h3`。

## 提交、查询与下载

新集成可使用 Videos 异步接口：

```bash
curl --fail-with-body https://llm.ziy.cc/v1/videos \
  -H 'Authorization: Bearer sk-你的密钥' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "minimax-video-h3",
    "prompt": "一艘蓝色陶瓷小船在平静水面轻轻摇晃，柔和灯光，固定镜头",
    "seconds": 4,
    "resolution": "768P",
    "ratio": "16:9",
    "aigc_watermark": false
  }'
```

保存响应的 `id`（KUNPO 任务 ID）。提交响应包含 `object: "video"`、`status: "queued"`、`progress` 和 `created_at`。

```bash
curl --fail-with-body https://llm.ziy.cc/v1/videos/task_你的任务ID \
  -H 'Authorization: Bearer sk-你的密钥'
```

| 查询 `status` | 含义与操作 |
|---------------|------------|
| `queued` / `in_progress` | 非终态，约 5 秒后继续查询 |
| `completed` | 成功终态，读取 `url` 或下载 `/content` |
| `failed` | 失败终态，读取 `error.message`，停止轮询 |
| `unknown` | 状态暂不明确，保留 ID 并有限次数重查 |

HTTP 200 本身不代表生成成功。客户端等待超时后继续查询同一个 ID；不要自动重发 POST。接口不承诺按客户端请求去重，重复 POST 可能生成多个收费任务。

```bash
curl --fail-with-body --location \
  https://llm.ziy.cc/v1/videos/task_你的任务ID/content \
  -H 'Authorization: Bearer sk-你的密钥' \
  --output video.mp4
```

`/content` 支持 GET、HEAD 和 Range，请使用同一用户的有效 API Key。没有权限不能读取其他用户的任务或视频。

## 参数

以下参数用于 Videos 与兼容任务接口提交。Responses 将提示词放在 `input`，其余参数同样可放在 `metadata`。

| 字段 | JSON 类型 | 规则 |
|------|-----------|------|
| `model` | string | 必填，`minimax-video-h3` |
| `prompt` | string | 与 `content` 中的文本合并；合并后至少一段非空文本 |
| `seconds` | integer | 4–15；优先于 `duration`、`metadata.duration`；均未提供时为 5 |
| `resolution` | string | `768P` / `2K`，默认 `768P`；优先于 `metadata.resolution`、`size`、`metadata.size` |
| `size` | string | 分辨率兼容字段，只接受 `768P` / `2K`；不能填 `1280x720` |
| `ratio` | string | `21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`adaptive`；纯文本不能为 `adaptive` |
| `aspect_ratio` | string | `ratio` 的别名，优先级为顶层 `ratio`、顶层 `aspect_ratio`、metadata 中的同名字段 |
| `aigc_watermark` | boolean | 默认 false；也接受 `watermark` 别名，优先级为顶层 `aigc_watermark`、metadata 同名字段、顶层 `watermark`、metadata 同名字段 |
| `content` | array | 文本与参考素材；顶层优先于 `metadata.content` |
| `metadata` | object | 可放 `prompt`、`duration`、`resolution`、`size`、比例、水印及 `content` |

768P / 2K 不接受 1080P / 4K 作为别名。首尾帧模式固定使用 `adaptive`，画幅由图片决定；多模态参考模式默认 `adaptive`，也可显式指定比例。请使用本页列出的参数。

## 首尾帧与多模态参考

`content` 每项使用以下结构；`url` 替换为你的公开素材地址：

```json
{
  "type": "image_url",
  "image_url": { "url": "你的公网图片URL" },
  "role": "first_frame"
}
```

| `type` | URL 字段 | `role` |
|--------|----------|--------|
| `text` | 使用 `text` 字符串，不使用 URL | 无 |
| `image_url` | `image_url.url` | `first_frame`（默认）、`last_frame`、`reference_image` |
| `video_url` | `video_url.url` | `reference_video`（默认） |
| `audio_url` | `audio_url.url` | `reference_audio`（默认） |

- 首帧和尾帧各最多一张；尾帧必须配首帧。首尾帧不能与任何 `reference_*` 素材混用。
- 多模态参考最多 9 张图片、3 段视频、3 段音频，素材合计最多 12 项；不能只有音频参考。
- 图片接受 HTTP(S) URL 或 PNG/JPEG/WebP 的 Base64 data URL。不接受裸 Base64；本接口不支持 multipart 文件直传。multipart 只可传字段，`metadata` / `content` 要编码为 JSON 字符串。
- 视频须为公开 HTTP(S) 地址、标准非分片且自包含的 MP4/MOV，时长每段 2–15 秒、合计不超过 15 秒。网关限 30 秒内完成下载，所有参考视频合计最多 64 MiB；每段不超过 50 MB、H.264/H.265 编码。
- 图片限制为每张 30 MB、边长 256–5760 像素；音频为 MP3/WAV、每段不超过 15 MB、每段 2–15 秒且合计不超过 15 秒。图片尺寸、编码及音频时长会在生成时校验，失败时查看任务错误。

参考视频示例，在 shell 环境中设置 `REFERENCE_VIDEO_URL`：

```python
import os
import requests

response = requests.post(
    "https://llm.ziy.cc/v1/videos",
    headers={"Authorization": "Bearer " + os.environ["KUNPO_API_KEY"]},
    json={
        "model": "minimax-video-h3",
        "prompt": "沿用参考视频的镜头运动，将小船改为白色",
        "seconds": 4,
        "resolution": "2K",
        "metadata": {"content": [{
            "type": "video_url",
            "video_url": {"url": os.environ["REFERENCE_VIDEO_URL"]},
            "role": "reference_video"
        }]}
    },
    timeout=(15, 120),
)
response.raise_for_status()
print(response.json()["id"])
```

## 其他协议

| 协议 | 提交 | 查询 | 返回结构 |
|------|------|------|----------|
| Videos | `POST /v1/videos` | `GET /v1/videos/:task_id` | `id`、小写 `status`、成功后的 `url` |
| 兼容任务接口 | `POST /tencent-tokenhub/v1/videos` | `GET /tencent-tokenhub/v1/videos/:task_id` | 提交为 `task_id`、`status`；查询为 `task.id`、大写 `task.status`、`task.content.url` |
| Responses | `POST /v1/responses` | `GET /v1/responses/:response_id` | `id`、Responses 状态、成功后的 `output[].content[].text` |

原生查询非终态为 `NOT_START` / `SUBMITTED` / `QUEUED` / `IN_PROGRESS`，成功为 `SUCCESS`，失败为 `FAILURE`，状态不明为 `UNKNOWN`。不能混用不同协议的 JSON 字段与状态枚举；查询时使用提交响应返回的 ID。

Responses 支持 `stream: true`、同步及 `background: true`。后台模式适合长任务：

```bash
curl --fail-with-body https://llm.ziy.cc/v1/responses \
  -H 'Authorization: Bearer sk-你的密钥' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "minimax-video-h3",
    "input": "蓝色陶瓷小船缓慢摇晃，柔和灯光",
    "background": true,
    "metadata": {"duration": 4, "resolution": "768P", "ratio": "16:9"}
  }'
```

保存响应 `id`，使用同一 Key 查询 `/v1/responses/:response_id`。`queued` / `in_progress` 继续查询，`completed` 成功，`failed` 停止并读取错误。成功文本包含 `<video>` 标签，其 `src` 为视频产物地址；不要假定 Responses 顶层存在 `url`。`input` 可以为字符串或消息内容数组，不能与 `prompt` 或 `content` 同时提供。

## 存储与计费

主视频成功后自动保存至 KUNPO CDN；Videos 的 `url` 和原生 `task.content.url` 优先返回归档地址。归档失败时可能返回临时地址（约 12 小时有效），调用方应及时下载。内联图片会转存并去重；外部图片与音频仍按原地址提交。

网关先下载、测量并保存参考视频的固定副本，再开始生成。测长发生在预算校验之前，额度不足时也可能已保存输入副本，但不会因此创建生成任务。客户端填写的计费秒数不能替代网关测量。

标准价格为 USD，不含用户分组倍率：

| 分辨率 | 输入参考视频 | 输出视频 | 第 6–9 张参考图 |
|--------|--------------|----------|----------------|
| 768P | $0.08 / 秒 | $0.08 / 秒 | $0.04 / 张 |
| 2K | $0.13 / 秒 | $0.13 / 秒 | $0.04 / 张 |

前五张参考图不收图片附加费；文本与音频参考不另收该项费用。

`费用 = (输入视频秒数 + 输出视频秒数) × 对应秒价 + max(图片数 − 5, 0) × 0.04`，再乘实际分组倍率。例：768P、4 秒输出、无视频参考和额外图片，标准费用为 0.32 USD；同条件 2K 为 0.52 USD。

预扣使用测得输入总时长向上取整到秒、请求输出时长及实际额外图片数。成功后按实际输入／输出秒数结算；缺失或全零用量保留可信测量与请求时长，不按零元处理。任务失败按网关失败结算退回预扣。实际单价与分组倍率以[模型广场](https://llm.ziy.cc/pricing)为准。

参数错误通常在提交阶段返回 HTTP 400；权限或余额不足需检查密钥、模型权限与账户额度。查询偶发网络错误时保留 ID 重试查询。参考视频下载失败需检查公网可达性、格式与时长；任务被拒绝或生成失败时查看任务错误信息。
