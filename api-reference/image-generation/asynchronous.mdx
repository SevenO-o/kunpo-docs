# 异步图片生成

异步接口适用于耗时较长的图片生成任务。提交后立即返回任务 ID，服务端定时轮询上游状态，客户端可随时查询进度和结果。

<Note>
  异步任务接口接受 `Image-GI`、`Image-GI2`、`Image-GPT2` 和 `Image-MI`。其中 `Image-GPT2` 是长耗时任务的推荐使用场景；各模型的专属参数见[模型指南](/api-reference/image-generation/overview#选择模型)。
</Note>

<Note>
  `qwen-image-3.0-pro` 仅支持[同步接口](/api-reference/image-generation/synchronous)，请勿用于本页接口。
</Note>

## 提交任务

```
POST https://llm.ziy.cc/v1/images/tasks
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `model` | string | **是** | `Image-GI`、`Image-GI2`、`Image-GPT2` 或 `Image-MI` |
| `prompt` | string | **是** | 图片描述文本 |
| `size` | string | 否 | 模型专属尺寸字段；规则见对应模型指南 |
| `images` | string[] | 否 | 模型支持图生图时使用的参考图 URL 数组 |
| `metadata` | object | 否 | 模型专属附加参数，例如 `quality`、`output_format`、`background`、`input_fidelity` |

### 提交响应

```json
{
  "id": "task_xxxxxxxxxxxx",
  "task_id": "task_xxxxxxxxxxxx",
  "model": "Image-GPT2",
  "status": "submitted",
  "created_at": 1715689600
}
```

| 字段 | 说明 |
|------|------|
| `task_id` | 任务 ID，用于后续查询 |
| `status` | 初始状态，固定为 `submitted` |
| `created_at` | 创建时间戳 |

## 查询任务

```
GET https://llm.ziy.cc/v1/images/tasks/:task_id
```

### 查询响应

```json
{
  "code": "success",
  "data": {
    "task_id": "task_xxxxxxxxxxxx",
    "status": "SUCCESS",
    "result_url": "https://kunpoapiimg.ziy.cc/...",
    "fail_reason": ""
  }
}
```

| 字段 | 说明 |
|------|------|
| `data.task_id` | 任务 ID |
| `data.status` | 任务状态（见下表） |
| `data.result_url` | 图片永久 CDN URL（仅 `SUCCESS` 时可用） |
| `data.fail_reason` | 失败原因（仅 `FAILURE` 时有值） |

### 任务状态

| 状态 | 说明 |
|------|------|
| `submitted` / `QUEUED` | 已提交，等待处理 |
| `IN_PROGRESS` | 生成中 |
| `SUCCESS` | 完成，`result_url` 可用 |
| `FAILURE` | 失败，查看 `fail_reason` |

### 查询示例

```bash
curl -X GET https://llm.ziy.cc/v1/images/tasks/task_xxxxxxxxxxxx \
  -H "Authorization: Bearer sk-你的密钥"
```

<Tip>
  建议每 10-15 秒轮询一次，直到 `status` 变为 `SUCCESS` 或 `FAILURE`。
</Tip>

## 完整异步工作流（Python）

```python
import time
import requests

BASE_URL = "https://llm.ziy.cc"
HEADERS = {"Authorization": "Bearer sk-你的密钥"}

def generate_image(prompt, model="Image-GPT2", size="1536x1024"):
    """提交异步图片生成任务并轮询至完成。"""
    response = requests.post(f"{BASE_URL}/v1/images/tasks", headers=HEADERS, json={
        "model": model,
        "prompt": prompt,
        "size": size,
        "metadata": {"quality": "high"},
    })
    task_id = response.json()["task_id"]

    while True:
        response = requests.get(f"{BASE_URL}/v1/images/tasks/{task_id}", headers=HEADERS)
        data = response.json()["data"]
        if data["status"] == "SUCCESS":
            return data["result_url"]
        if data["status"] == "FAILURE":
            raise RuntimeError(data["fail_reason"])
        time.sleep(15)
```
