<span id="kunpo-api" />

统一的大模型网关，兼容 OpenAI 接口格式。通过一个 API Key，即可调用 Claude、GPT、Gemini、DeepSeek、Qwen、GLM 等 150+ 主流模型。

<span id="核心能力" />

## 按用途开始

<CardGroup cols={2}>
  <Card title="文本对话" icon="message" href="/api-reference/text-chat">
    OpenAI 兼容的 Chat Completions 接口，支持流式输出
  </Card>
  <Card title="图像生成" icon="image" href="/api-reference/image-generation/overview">
    支持 Nano Banana Pro、Nano Banana 2、GPT Image 2、Midjourney、Qwen Image 3.0 Pro 五款生图模型
  </Card>
  <Card title="音频生成" icon="volume-high" href="/api-reference/seed-audio">
    生成音效、环境音或语音音频，兼容 OpenAI Audio Speech 请求参数与豆包原生参数。
  </Card>
  <Card title="视频生成" icon="video" href="/api-reference/doubao-video">
    Seedance 2.0 与腾讯 SE 两个系列，支持文生视频、图生视频、首尾帧控制等异步任务模式。
  </Card>
  <Card title="3D 模型生成" icon="cube" href="/api-reference/tripo-3d">
    Tripo 文生 3D 与图生 3D，异步任务出 GLB 模型与渲染预览图。
  </Card>
</CardGroup>
