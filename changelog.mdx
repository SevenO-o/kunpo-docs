<Update label="2026-09-29" tags={["模型", "Claude"]}>

## Claude Sonnet 5.5

新增 `claude-sonnet-5-5`，支持 Messages 与 Chat Completions，适合日常编程、代码审查、文档分析和写作。使用现有 KUNPO API Key；开启模型白名单时请加入新模型 ID。

调用方法、上下文与缓存价格见 [Claude Sonnet 5.5](/api-reference/claude-sonnet-55)。

</Update>

<Update label="2026-09-28" tags={["Jev Router", "文本生成"]}>

## Jev Router 自动选模对话

新增 `typesafe/jev-router`，可根据任务自动选择模型，适合问答、摘要、翻译、文案草稿与代码解释。使用专用 Base URL，并关闭流式输出；费用随实际选中的模型与用量变化。

接入示例与费用说明见 [Jev Router](/api-reference/jev-router)。

</Update>

<Update label="2026-09-23" tags={["Jev", "结构化决策"]}>

## Jev 结构化决策

新增 `~typesafe/jev-latest` 与兼容别名 `jev-latest`，适合分类、工单分流、评分和布尔概率判断。使用 `/v1/decisions` 提交 `state` 与 `questions`，同步读取 `answers`；不使用聊天接口。

完整字段和定价见 [Jev 结构化决策](/api-reference/jev)。

</Update>

<Update label="2026-09-23" tags={["GPT-6", "Opus 5.5"]}>

## GPT-6 Luna / Sol 与 Claude Opus 5.5

新增 `gpt-6-luna`、`gpt-6-sol` 和 `claude-opus-5-5`。沿用现有 KUNPO API Key；开启模型限制时需加入对应完整 ID。

GPT-6 支持 Chat Completions 与 Responses；Opus 5.5 推荐 Messages。Opus 的思考与工具选择规则与旧版不同，接入前请阅读 [GPT-6](/api-reference/gpt-6) 和 [Opus 5.5](/api-reference/claude-opus-55)。

</Update>

<Update label="2026-09-23" tags={["MiniMax H3", "视频"]}>

## MiniMax H3 视频

新增 `minimax-video-h3`，支持 4–15 秒、768P / 2K、首尾帧及图片、视频、音频参考，适合短视频创作和多素材参考生成。可使用 Videos、Responses 或兼容任务接口。

调用示例、素材限制和按秒价格见 [MiniMax H3](/api-reference/minimax-h3)。

</Update>

<Update label="2026-09-17" tags={["Tripo", "3D"]}>

## 3D 模型自动绑定与动画

新增绑定检查、自动骨骼绑定和动画重定向，可将已生成的 3D 模型制作成带骨骼、带动作的 GLB / FBX。支持多动作及原地播放；开启模型限制时需加入绑定模型 ID。

参数与串接示例见 [Tripo 自动绑定与动画](/api-reference/tripo-3d#自动绑定与动画)。

</Update>

<Update label="2026-09-16" tags={["价格展示"]}>

## 按实际计费单位查看价格

模型广场支持查看图片按尺寸和张数、音频按分钟、视频按输入与输出秒数的价格。现有计费规则不变，调用方无需修改请求参数。

各模型的具体单位、分档和费用计算方式见对应模型页及[模型广场](https://llm.ziy.cc/pricing)。

</Update>

<Update label="2026-09-16" tags={["Seedance 2.5", "Seedream 5.0 Pro"]}>

## Seedance 2.5 与 Seedream 5.0 Pro

新增 [Seedance 2.5](/api-reference/seedance-25) 视频与 [Seedream 5.0 Pro 完整参数接口](/api-reference/image-generation/models/seedream-50-pro)。支持视频自动时长、参考视频编辑与延长，以及图片提示词优化和图层拆分。

视频按输入与输出秒数计费；图片按输出尺寸与张数计费，图层逐张结算。已有模型的调用方式保留。

</Update>

<Update label="2026-09-16" tags={["VS 2.5", "视频"]}>

## VS 2.5 视频

新增 [VS 2.5](/api-reference/video-vs25)，支持 Videos、Responses 与兼容任务接口，可使用图片、视频、音频参考及首尾帧，输出分辨率覆盖 480P 至 4K。

首帧模式需用 `adaptive`，不支持 `-1` 自动时长或媒体文件直传。完整素材限制、任务查询与价格见模型页。

文档同时提供 [llms.txt](https://docs.ziy.cc/llms.txt) 和各页面的 Markdown，方便 AI 读取接入说明。

</Update>

<Update label="2026-09-11" tags={["图片"]}>

## GPT Images 2.5

新增 `gpt-image-2.5-flare` 与 `gpt-image-2.5-sunburst`，支持同步生图和编辑。编辑可传图片 URL 或本地文件，按 token 用量计费。

模型选择、参数和示例见 [GPT Images 2.5](/api-reference/image-generation/models/gpt-image-2.5)。

</Update>

<Update label="2026-09-10" tags={["Tripo", "多图参考"]}>

## 3D 生成支持多视角参考

新增 `multiview-to-model` 多视角生 3D 与 `image-to-multiview` 单图生成四视角图片。可先补齐视角，再复用任务 ID 生成模型。

原有 `image-to-model` 仍只接受一张参考图；需要多图时请使用新接口。用法与价格见 [Tripo](/api-reference/tripo-3d)。

</Update>

<Update label="2026-09-09" tags={["修复"]}>

## 异步图生图支持 Base64 参考图

修复 `Image-GI` / `Image-GI2` 通过 `/v1/images/tasks` 传 Base64 参考图时的 502 错误。同步与异步接口均可在 `images` 中使用 Base64、data URL 或公网 URL。

参考图格式见[异步图片调用](/api-reference/image-generation/asynchronous)。

</Update>

<Update label="2026-09-09" tags={["Tripo", "3D"]}>

## 新增 3D 模型生成

新增 Tripo 文本与单图生成 3D 模型，异步获取 GLB 和预览图。图片支持 Base64、data URL 或公网 URL，无需先准备图片外链。

参数、轮询和下载方式见 [Tripo](/api-reference/tripo-3d)。

</Update>

<Update label="2026-09-08" tags={["修复"]}>

## 视频结果格式修正

修复 SE 视频结果地址后缀与内容类型不匹配导致部分播放器无法直接播放的问题。现在按视频格式返回 `.mp4` 与 `video/mp4`，旧链接仍可下载。

</Update>

<Update label="2026-09-07" tags={["行为变更"]}>

## 异步提交状态改为 queued

图片与旧视频异步接口的提交响应 `status` 从 `submitted` 改为 `queued`。若客户端依赖旧值，请更新判断逻辑；结合 HTTP 状态码与 `task_id` 判断是否成功提交。

轮询接口仍使用 `data.status` 和大写枚举，终态为 `SUCCESS` / `FAILURE`。详见[异步任务状态](/api-reference/image-generation/asynchronous#任务状态)。

</Update>

修复飞书登录偶发失败的问题。

</Update>
