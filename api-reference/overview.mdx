<span id="api-总览" />

KUNPO API 基于统一网关 `https://llm.ziy.cc`，兼容 OpenAI 与 Anthropic 主流接口格式。一个 API Key 即可访问文本、图片、音频、视频等多模态能力。

## 基础信息

| 项目 | 说明 |
|------|------|
| Base URL | `https://llm.ziy.cc` |
| 认证方式 | `Authorization: Bearer sk-你的密钥` |
| 文本协议 | OpenAI Chat Completions / Responses / Anthropic Messages |
| 图片协议 | OpenAI Images API（同步 + 异步） |
| 音频协议 | OpenAI Audio Speech 兼容请求 + 音频二进制响应 |
| 视频协议 | 异步任务（提交 + 轮询） |

<Note>
  尚未获取 API Key？请先阅读 [快速开始](/quick-start)。
</Note>

| 能力 | 方法 | 路径 | 说明 |

| 图像生成（异步提交） | `POST` | `/v1/images/tasks` | 返回 `task_id`，适合长耗时模型 |
| 图像生成（异步查询） | `GET` | `/v1/images/tasks/:task_id` | 查询任务状态与结果 URL |

| VS 2.5 Videos | `POST` / `GET` | `/v1/videos`<br />`/v1/videos/:task_id` | 提交、查询，成功结果在 `url` |

| MiniMax H3 | `POST` / `GET` | `/v1/videos`<br />`/v1/videos/:task_id` | 另支持 Responses 与兼容任务接口；见 [H3 契约与计费](/api-reference/minimax-h3) |

| VS 2.5 兼容任务接口 | `POST` / `GET` | `/tencent-vod/v1/videos`<br />`/tencent-vod/v1/videos/:task_id` | `Response` 外层结构；见[完整契约](/api-reference/video-vs25) |

| 3D 贴图与模型处理 | `POST` | `/tripo/v3/models/texture` 等 | [完整端点与参数](/api-reference/tripo-3d#接口地址) |
| 3D 文件与批量查询 | `POST` | `/tripo/v3/files`、`/tripo/v3/files/presign`、`/tripo/v3/tasks/list` | [上传与导入](/api-reference/tripo-3d#文件上传与导入) |
| 3D 生成（查询） | `GET` | `/tripo/v3/tasks/:task_id` | 查询任务状态 |
| 3D 产物（列出 / 下载） | `GET` | `/v1/tasks/:task_id/artifacts` | 取 GLB 模型与预览图 |

## 协议格式对比

| 对比项 | Chat Completions | Messages API |
|--------|-----------------|--------------|
| 路径 | `/v1/chat/completions` | `/v1/messages` |
| 模型 ID 示例 | `anthropic/claude-sonnet-4.6` | `Claude-Sonnet-4.6` |

<Tip>
  不确定用哪种格式？通用集成选 Chat Completions；Claude Code 或 Anthropic SDK 选 Messages API。
</Tip>

## 同步 vs 异步

部分能力提供两种调用模式：

| 模式 | 特点 | 适用接口 |
|------|------|----------|
| **同步** | 请求阻塞至任务完成，直接返回结果 | 文本对话、图片 GI/GI2/MI/Qwen Image 3.0 Pro/Seedream 5.0 Pro、豆包 Seed Audio |
| **异步** | 提交后返回任务 ID，客户端轮询结果 | 图片 Image-GPT2、豆包视频、SE 视频、VS 2.5 |

图片任务及豆包 / SE 旧视频接口的轮询流程：

```
1. POST 提交任务 → 获取 task_id（响应 status 为小写 queued）
2. GET  轮询状态 → 直至 data.status 为 SUCCESS 或 FAILURE
3. 读取 data.result_url
```

VS 2.5 的 Videos、Responses 和兼容任务接口各自使用不同 ID、状态和结果字段；请按 [VS 2.5 接口契约](/api-reference/video-vs25#protocols)解析。不要把旧接口的 `data.status` 套用到新接口。

## 常见 HTTP 状态码

| 状态码 | 含义 | 处理建议 |
|:------:|------|----------|
| `200` | 成功 | — |
| `400` | 请求参数错误 | 检查 JSON 格式与必填字段 |
| `401` | API Key 无效 | 检查 Authorization 头 |
| `429` | 请求频率超限 | 降低频率，稍后重试 |
| `503` | 模型无可用通道 | 确认模型名正确，或在控制台查看分组权限 |
| `502` / `504` | 网关超时 | 长耗时请求请耐心等待或改用异步接口 |

各接口的详细参数、示例与错误说明请参阅对应文档页。
