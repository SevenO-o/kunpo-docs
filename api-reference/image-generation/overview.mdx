# 图片生成

KUNPO 网关统一封装多款图片生成能力，兼容 OpenAI `images` 接口格式。一个 API Key 即可调用，无需关心上游鉴权细节。请先选择模型，再查看对应的能力、参数规则和示例。

## 选择模型

调用时在 `model` 参数中传入 API 模型名；产品展示名仅用于识别。

| API 模型名 | 对应名称 | 能力 | 典型耗时 | 指南 |
|------------|----------|------|----------|------|
| `Image-GI` | Nano Banana Pro | 文生图、图生图（参考图 URL） | 30-60 秒 | [查看指南](/api-reference/image-generation/models/nano-banana-pro) |
| `Image-GI2` | Nano Banana 2 | 文生图（升级版，画质更佳） | 30-60 秒 | [查看指南](/api-reference/image-generation/models/nano-banana-2) |
| `Image-GPT2` | GPT Image 2 | 高质量文生图、合法自定义像素尺寸 | 数分钟 | [查看指南](/api-reference/image-generation/models/gpt-image-2) |
| `Image-MI` | Midjourney | Midjourney 风格文生图，一次返回 4 张 | 30-60 秒 | [查看指南](/api-reference/image-generation/models/midjourney) |
| `qwen-image-3.0-pro` | Qwen Image 3.0 Pro | 文生图、多模态文生图与图生图、复杂版式与文字渲染 | 约 50-60 秒/张 | [查看指南](/api-reference/image-generation/models/qwen-image-3-pro) |

<Note>
  请求示例与 SDK 调用必须使用 API 模型名（如 `Image-GI`）；不要将展示名写入 `model` 参数。
</Note>

### 选择建议

| 场景 | 推荐模型 | 原因 |
|------|----------|------|
| 日常文生图、快速出图 | [Nano Banana 2（`Image-GI2`）](/api-reference/image-generation/models/nano-banana-2) | 速度快、性价比高 |
| 复杂图文排版、中文小字与界面素材生成 | [Qwen Image 3.0 Pro（`qwen-image-3.0-pro`）](/api-reference/image-generation/models/qwen-image-3-pro) | 擅长高密度信息版式、文字渲染与界面仿真；注意 1 RPM 限流 |
| 图生图 / 风格迁移 | [Nano Banana Pro（`Image-GI`）](/api-reference/image-generation/models/nano-banana-pro) | 支持传入参考图 URL |
| 高质量精细出图 | [GPT Image 2（`Image-GPT2`）](/api-reference/image-generation/models/gpt-image-2) | 画质更好，长耗时任务建议走异步接口 |
| 一次生成多张候选图 | [Midjourney（`Image-MI`）](/api-reference/image-generation/models/midjourney) | 单次请求固定返回 4 张 |

## 调用方式

  <Card title="同步接口" href="/api-reference/image-generation/synchronous">

模型支持的调用方式、最小请求和模型专属字段见各模型指南；同步与异步页面只说明公共协议。

## 共享平台约定

### 认证

```
Authorization: Bearer sk-你的密钥
```

### 图片存储

生成的图片自动转存至 KUNPO 图床（COS），返回永久 CDN 链接（`https://kunpoapiimg.ziy.cc/...`），不受上游临时 URL 过期限制。

### 公共参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `model` | string | **是** | API 模型名；从上方模型表选择 |
| `prompt` | string | **是** | 图片描述文本 |
| `response_format` | string | 否 | 目前仅支持 `url`（默认）；传入 `b64_json` 仍返回 URL |

`size`、`quality`、参考图和其他扩展字段的支持情况因模型而异。请从模型指南进入，不要将某一模型的参数规则套用于其他模型。
