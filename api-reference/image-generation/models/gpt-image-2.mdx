# GPT Image 2（Image-GPT2）

请求时使用 API 模型名 `Image-GPT2`；GPT Image 2 仅为展示名称。

## 适用场景

- 高质量、精细的文生图
- 需要精确控制合法输出像素尺寸的场景

## 调用方式

`Image-GPT2` 支持[同步图片生成](/api-reference/image-generation/synchronous)，但生成可能耗时数分钟。长耗时任务建议使用[异步图片生成](/api-reference/image-generation/asynchronous)。

## 最小同步示例

```bash
curl -X POST https://llm.ziy.cc/v1/images/generations \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Image-GPT2",
    "prompt": "扁平插画，一杯咖啡",
    "size": "1024x1536",
    "quality": "medium",
    "output_format": "png"
  }'
```

<Note>
  即使传入 `response_format: "b64_json"`，实际返回仍是图片 URL，而非 Base64 数据。
</Note>

## 尺寸与质量规则

### 标准比例

| 标准比例 | `size` 映射 |
|----------|-------------|
| 1:1 | `1024x1024` |
| 16:9 | `1536x864` |
| 9:16 | `864x1536` |
| 4:3 | `1024x768` |
| 3:4 | `768x1024` |
| 3:2 | `1536x1024` |
| 2:3 | `1024x1536` |
| `auto` | 支持 |

未传 `size` 时默认返回 `1024×1024`。

### 自定义尺寸

KUNPO 网关支持合法的自定义 `WxH`。宽、高必须为正整数且均为 16 的倍数；单边不超过 3840；宽高比 `W/H` 在 `1/3` 至 `3` 之间；总像素数 `W×H` 在 `655,360` 至 `8,294,400` 之间（均含边界）。满足条件时按请求尺寸处理，否则回退为 `1024×1024`。

### `quality` 与 GPT 专属参数

| `quality` | 作用 |
|-----------|------|
| `low` | 低画质档位 |
| `medium` | 中等画质档位（默认） |
| `high` | 高画质档位 |

| 参数 | 说明 |
|------|------|
| `background` | 背景描述 |
| `output_format` | 输出格式，默认 `png` |
| `input_fidelity` | `high` 或 `low` |

## 限制与常见误用

- `size` 支持标准比例和满足约束的自定义 `WxH`；不满足约束时回退为 `1024×1024`。
- `quality` 决定画质档位，不等同于输出像素尺寸。
- 同步接口最长等待约 15 分钟；较长任务应使用异步接口。
