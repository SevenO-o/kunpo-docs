<span id="通用-openai-兼容客户端" />

KUNPO API 完全兼容 OpenAI 接口格式。任何支持自定义 OpenAI API 端点的工具都可以直接接入。

## 连接信息

| 字段 | 值 |
|------|------|
| API Base URL | `https://llm.ziy.cc/v1` |
| API Key | `sk-你的密钥`（从后台获取） |

---

## 代码示例

<CodeGroup>
  ```python Python (OpenAI SDK)
  from openai import OpenAI

  client = OpenAI(
      base_url="https://llm.ziy.cc/v1",
      api_key="sk-你的密钥"
  )

  response = client.chat.completions.create(
      model="anthropic/claude-sonnet-4.6",
      messages=[{"role": "user", "content": "你好"}]
  )

  print(response.choices[0].message.content)
  ```

  ```javascript Node.js (OpenAI SDK)
  import OpenAI from "openai";

  const client = new OpenAI({
    baseURL: "https://llm.ziy.cc/v1",
    apiKey: "sk-你的密钥",
  });

  const response = await client.chat.completions.create({
    model: "anthropic/claude-sonnet-4.6",
    messages: [{ role: "user", content: "你好" }],
  });

  console.log(response.choices[0].message.content);
  ```

  ```bash 环境变量
  export OPENAI_API_BASE=https://llm.ziy.cc/v1
  export OPENAI_API_KEY=sk-你的密钥
  ```
</CodeGroup>

## 填写模型 ID

在客户端的模型名称或模型 ID 字段中，填写 [KUNPO API 模型广场](https://llm.ziy.cc/pricing) 中所选模型的完整 ID。保留其前缀、大小写和版本号，不要根据供应商名称自行添加或删除前缀。

模型 ID 示例包括 `anthropic/claude-sonnet-4.6`、`openai/gpt-5.4`、`google/gemini-2.5-pro`、`DeepSeek-R1`、`Qwen3`、`GLM-4`。这些示例不能用于推断同一供应商其他模型的命名。
