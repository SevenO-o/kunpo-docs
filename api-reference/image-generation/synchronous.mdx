```
POST https://llm.ziy.cc/v1/images/generations
```

提交图像生成任务并同步等待结果返回。网关提交后每 2 秒轮询，直至完成（最长约 15 分钟）。

适用于[模型选择表](/api-reference/image-generation/overview#支持模型)中所有支持同步的模型。模型的专属参数和示例请直接进入对应模型页。

<Warning>
  同步接口最长等待约 15 分钟，客户端或中间代理可能更早超时。GPT Image 2 等长耗时模型建议使用[异步任务](/api-reference/image-generation/asynchronous)。
</Warning>

认证方式见[图像生成认证](/api-reference/image-generation/overview#认证)。

## 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `model` | string | **是** | [模型选择表](/api-reference/image-generation/overview#支持模型)中的 API 调用名 |
| `prompt` | string | **是** | 图片描述文本；Qwen 多模态请求也需保留 |
| `size` | string | 否 | 输出尺寸或比例，含义与限制见各模型页 |
| `quality` | string | 否 | 质量或分辨率档位，适用范围与取值见各模型页 |
| `response_format` | string | 否 | 默认 `url`；传入 `b64_json` 仍返回 URL，`b64_json` 为空 |
| `images` | string[] | 否 | 参考图数组，输入规则见各模型的图生图章节 |
| `image` | string | 否 | 单张参考图（URL 或 Base64）；Qwen 请使用多模态结构 |

### 模型扩展字段

| 参数 | 类型 | 适用模型与说明 |
|------|------|----------------|
| `input` | object | Qwen 多模态请求必填；结构见 [Qwen 图生图](/api-reference/image-generation/models/qwen-image-3-pro#图生图) |
| `parameters` | object | Qwen 多模态参数容器；见 [Qwen 示例](/api-reference/image-generation/models/qwen-image-3-pro#多模态文生图) |
| `background` | string | GPT Image 2 背景模式，见[透明背景](/api-reference/image-generation/models/gpt-image-2#透明背景) |
| `output_format` | string | GPT Image 2 图片文件格式，见[专属参数](/api-reference/image-generation/models/gpt-image-2#画质与专属参数) |
| `input_fidelity` | string | GPT Image 2 参考图参数，见[专属参数](/api-reference/image-generation/models/gpt-image-2#画质与专属参数) |

不要把参数表中的所有字段一起传给每个模型。请先使用模型页的最小示例，再按需要增加参数。

## 响应格式

```json
{
  "created": 1715689600,
  "data": [
    { "url": "https://kunpoapiimg.ziy.cc/..." }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `created` | 请求创建时间戳 |
| `data[].url` | 图片永久 CDN 地址 |

## 示例

<CodeGroup>
  ```bash cURL
  curl -X POST https://llm.ziy.cc/v1/images/generations \
    -H "Authorization: Bearer sk-你的密钥" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "Image-GI2",
      "prompt": "赛博朋克风格的武汉长江大桥夜景",
      "size": "1536x1024",
      "quality": "high"
    }'
  ```

  ```python Python
  import requests

  resp = requests.post(
      "https://llm.ziy.cc/v1/images/generations",
      headers={"Authorization": "Bearer sk-你的密钥"},
      json={
          "model": "Image-GI2",
          "prompt": "赛博朋克风格的武汉长江大桥夜景",
          "size": "1536x1024",
          "quality": "high"
      }
  )

  resp.raise_for_status()
  url = resp.json()["data"][0]["url"]
  print(f"图片地址: {url}")
  ```

  ```javascript Node.js
  const resp = await fetch("https://llm.ziy.cc/v1/images/generations", {
    method: "POST",
    headers: {
      Authorization: "Bearer sk-你的密钥",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "Image-GI2",
      prompt: "赛博朋克风格的武汉长江大桥夜景",
      size: "1536x1024",
      quality: "high",
    }),
  });

  if (!resp.ok) throw new Error(`HTTP ${resp.status}`);
  const { data } = await resp.json();
  console.log(`图片地址: ${data[0].url}`);
  ```

  ```python Python (OpenAI SDK)
  from openai import OpenAI

  client = OpenAI(
      base_url="https://llm.ziy.cc/v1",
      api_key="sk-你的密钥"
  )

  response = client.images.generate(
      model="Image-GI2",
      prompt="赛博朋克风格的武汉长江大桥夜景",
      size="1536x1024",
      quality="high"
  )

  print(response.data[0].url)
  ```
</CodeGroup>

## 等待与错误处理

通用错误含义见 [HTTP 状态码](/api-reference/overview#常见-http-状态码)。遇到超时，先检查客户端与代理的等待时间；长耗时模型优先采用异步方式。不要把一次超时直接当成任务已失败并自动重复提交。
