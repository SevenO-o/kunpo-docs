`size` 控制输出比例，`quality` 控制分辨率档位。以下规则同时适用于 Nano Banana Pro（`Image-GI`）和 Nano Banana 2（`Image-GI2`）。

| 标准比例 | `size` 映射 |
|----------|-------------|
| 1:1 | `1024x1024` |
| 16:9 | `1792x1024`、`1536x1024`、`1280x720`、`1536x864` |
| 9:16 | `1024x1792`、`1024x1536`、`720x1280`、`864x1536` |
| `auto` | 不支持 |

Image-GI / Image-GI2 仅按比例处理，不按传入的 `WxH` 直出。未传 `size` 或传入未匹配尺寸时，按 1:1 处理，通常返回 `1024×1024`。

| `quality` | 分辨率档位 |
|-----------|------------|
| `low` | 1K |
| `medium` | 2K |
| `high` | 4K |
| 默认 / 空 | 1K |

<Warning>
  最终尺寸以实际返回图片为准。`size` 中的宽高用于匹配比例，不保证按这组像素尺寸输出。
</Warning>
