<span id="异步图片生成" />

异步接口适用于耗时较长的图像生成任务。提交后立即返回任务 ID，服务端定时轮询上游状态，客户端可随时查询进度和结果。

适用模型及推荐方式见[模型选择表](/api-reference/image-generation/overview#支持模型)。认证方式见[图像生成认证](/api-reference/image-generation/overview#认证)。

<Note>
  `qwen-image-3.0-pro` 仅支持同步接口 `POST /v1/images/generations`，请勿用于本页接口。
</Note>

## 提交任务

```
POST https://llm.ziy.cc/v1/images/tasks
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `model` | string | **是** | [模型选择表](/api-reference/image-generation/overview#支持模型)中支持异步的 API 调用名 |
| `prompt` | string | **是** | 图片描述文本 |
| `size` | string | 否 | 图片尺寸，规则见对应模型页 |
| `images` | string[] | 否 | 支持图生图的模型使用此参考图数组；支持 URL、Base64 或 data URL，具体用法见模型页 |
| `quality` | string | 否 | Image-GPT2 画质档位，也可通过 `metadata.quality` 传入；取值见 [模型参数](/api-reference/image-generation/models/gpt-image-2#画质与专属参数) |
| `background` | string | 否 | Image-GPT2 背景模式，可放在请求顶层或 `metadata.background`；取值见 [透明背景](/api-reference/image-generation/models/gpt-image-2#透明背景) |
| `output_format` | string | 否 | Image-GPT2 图片文件格式，可放在请求顶层或 `metadata.output_format`；透明背景的格式要求见 [模型说明](/api-reference/image-generation/models/gpt-image-2#透明背景) |
| `metadata` | object | 否 | 附加参数容器，可传入 `quality`、`output_format`、`background`、`input_fidelity` 等 |

### 提交响应

```json
{
  "id": "task_xxxxxxxxxxxx",
  "task_id": "task_xxxxxxxxxxxx",
  "model": "Image-GPT2",
  "status": "submitted",
  "created_at": 1715689600
}
```

| 字段 | 说明 |
|------|------|
| `task_id` | 任务 ID，用于后续查询 |
| `status` | 初始状态，固定为 `submitted` |
| `created_at` | 创建时间戳 |

### 示例

<CodeGroup>
  ```bash cURL
  curl -X POST https://llm.ziy.cc/v1/images/tasks \
    -H "Authorization: Bearer sk-你的密钥" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "Image-GPT2",
      "prompt": "高清产品摄影，蓝牙耳机",
      "size": "1536x1024",
      "metadata": { "quality": "high" }
    }'
  ```

  ```python Python
  import requests

  resp = requests.post(
      "https://llm.ziy.cc/v1/images/tasks",
      headers={"Authorization": "Bearer sk-你的密钥"},
      json={
          "model": "Image-GPT2",
          "prompt": "高清产品摄影，蓝牙耳机",
          "size": "1536x1024",
          "metadata": {"quality": "high"}
      }
  )

  resp.raise_for_status()
  task_id = resp.json()["task_id"]
  print(f"任务已提交: {task_id}")
  ```

  ```javascript Node.js
  const resp = await fetch("https://llm.ziy.cc/v1/images/tasks", {
    method: "POST",
    headers: {
      Authorization: "Bearer sk-你的密钥",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "Image-GPT2",
      prompt: "高清产品摄影，蓝牙耳机",
      size: "1536x1024",
      metadata: { quality: "high" },
    }),
  });

  if (!resp.ok) throw new Error(`HTTP ${resp.status}`);
  const { task_id } = await resp.json();
  console.log(`任务已提交: ${task_id}`);
  ```
</CodeGroup>

## 查询任务

```
GET https://llm.ziy.cc/v1/images/tasks/:task_id
```

### 查询响应

```json
{
  "code": "success",
  "data": {
    "task_id": "task_xxxxxxxxxxxx",
    "status": "SUCCESS",
    "result_url": "https://kunpoapiimg.ziy.cc/...",
    "fail_reason": ""
  }
}
```

| 字段 | 说明 |
|------|------|
| `data.task_id` | 任务 ID |
| `data.status` | 任务状态（见下表） |
| `data.result_url` | 图片永久 CDN URL（仅 `SUCCESS` 时可用） |
| `data.fail_reason` | 失败原因（仅 `FAILURE` 时有值） |

### 任务状态

| 状态 | 说明 |
|------|------|
| `submitted` / `QUEUED` | 已提交，等待处理 |
| `IN_PROGRESS` | 生成中 |
| `SUCCESS` | 完成，`result_url` 可用 |
| `FAILURE` | 失败，查看 `fail_reason` |

### 查询示例

<CodeGroup>
  ```bash cURL
  curl -X GET https://llm.ziy.cc/v1/images/tasks/task_xxxxxxxxxxxx \
    -H "Authorization: Bearer sk-你的密钥"
  ```

  ```python Python
  import requests

  resp = requests.get(
      "https://llm.ziy.cc/v1/images/tasks/task_xxxxxxxxxxxx",
      headers={"Authorization": "Bearer sk-你的密钥"}
  )

  resp.raise_for_status()
  data = resp.json()["data"]
  print(f"状态: {data['status']}")
  if data["status"] == "SUCCESS":
      print(f"图片地址: {data['result_url']}")
  ```

  ```javascript Node.js
  const resp = await fetch(
    "https://llm.ziy.cc/v1/images/tasks/task_xxxxxxxxxxxx",
    { headers: { Authorization: "Bearer sk-你的密钥" } }
  );

  if (!resp.ok) throw new Error(`HTTP ${resp.status}`);
  const { data } = await resp.json();
  console.log(`状态: ${data.status}`);
  if (data.status === "SUCCESS") {
    console.log(`图片地址: ${data.result_url}`);
  }
  ```
</CodeGroup>

<Tip>
  建议每 10-15 秒轮询一次，直到 `status` 变为 `SUCCESS` 或 `FAILURE`。
</Tip>

## 完整异步工作流（Python）

先保存提交响应中的 `task_id`。查询临时超时或遇到 `502` / `503` / `504` 时，继续查询同一个任务；不要重新提交生成请求。下面将提交与查询分开，查询超时后仍可用原任务 ID 恢复。

```python
import time
import requests

BASE_URL = "https://llm.ziy.cc"
HEADERS = {"Authorization": "Bearer sk-你的密钥"}

def wait_for_image(task_id, timeout=900):
    deadline = time.monotonic() + timeout
    while time.monotonic() < deadline:
        try:
            resp = requests.get(
                f"{BASE_URL}/v1/images/tasks/{task_id}",
                headers=HEADERS,
                timeout=30,
            )
        except (requests.Timeout, requests.ConnectionError):
            time.sleep(15)
            continue

        if resp.status_code in (502, 503, 504):
            time.sleep(15)
            continue
        resp.raise_for_status()
        data = resp.json()["data"]
        if data["status"] == "SUCCESS":
            return data["result_url"]
        if data["status"] == "FAILURE":
            raise RuntimeError(f"任务 {task_id} 失败: {data.get('fail_reason', '')}")
        time.sleep(15)

    raise TimeoutError(f"等待超时，任务不一定失败；保留 {task_id}，稍后继续查询")

# 只提交一次；如果提交未返回任务 ID，请先排查，不要自动重试 POST。
resp = requests.post(
    f"{BASE_URL}/v1/images/tasks",
    headers=HEADERS,
    json={"model": "Image-GPT2", "prompt": "赛博朋克风格的未来城市夜景"},
    timeout=60,
)
resp.raise_for_status()
task_id = resp.json()["task_id"]
print(f"请保存任务 ID: {task_id}")
print(wait_for_image(task_id))

# 恢复已有任务时，只调用 wait_for_image("已保存的任务 ID")。
```
