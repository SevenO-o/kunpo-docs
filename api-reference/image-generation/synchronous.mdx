# 同步图片生成

```
POST https://llm.ziy.cc/v1/images/generations
```

提交图片生成任务并同步等待结果返回。网关提交后每 2 秒轮询，直至完成（最长约 15 分钟）。先在模型指南确认所选模型的能力和专属参数，再使用本页的公共协议。

## 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `model` | string | **是** | API 模型名；从[图片生成概览](/api-reference/image-generation/overview)或上方模型指南选择 |
| `prompt` | string | **是** | 图片描述文本 |
| `response_format` | string | 否 | 目前仅支持 `url`（默认）；传入 `b64_json` 仍返回 URL |

`size`、`quality`、参考图、`input`、`parameters`、`background`、`output_format` 和 `input_fidelity` 均为模型专属字段。请只按对应[模型指南](/api-reference/image-generation/overview#选择模型)传入，避免将某模型的请求结构用于另一模型。

## 响应格式

```json
{
  "created": 1715689600,
  "data": [
    { "url": "https://kunpoapiimg.ziy.cc/..." }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `created` | 请求创建时间戳 |
| `data[].url` | 图片永久 CDN 地址 |

## 通用示例

以下示例使用 `Image-GI2`。更换模型时，请同时按对应模型指南调整专属参数。

<CodeGroup>
  ```bash cURL
  curl -X POST https://llm.ziy.cc/v1/images/generations \
    -H "Authorization: Bearer sk-你的密钥" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "Image-GI2",
      "prompt": "赛博朋克风格的武汉长江大桥夜景",
      "size": "1536x1024",
      "quality": "high"
    }'
  ```

  ```python Python
  import requests

  resp = requests.post(
      "https://llm.ziy.cc/v1/images/generations",
      headers={"Authorization": "Bearer sk-你的密钥"},
      json={
          "model": "Image-GI2",
          "prompt": "赛博朋克风格的武汉长江大桥夜景",
          "size": "1536x1024",
          "quality": "high"
      }
  )

  print(resp.json()["data"][0]["url"])
  ```

  ```javascript Node.js
  const resp = await fetch("https://llm.ziy.cc/v1/images/generations", {
    method: "POST",
    headers: {
      Authorization: "Bearer sk-你的密钥",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "Image-GI2",
      prompt: "赛博朋克风格的武汉长江大桥夜景",
      size: "1536x1024",
      quality: "high",
    }),
  });

  const { data } = await resp.json();
  console.log(data[0].url);
  ```

  ```python Python (OpenAI SDK)
  from openai import OpenAI

  client = OpenAI(
      base_url="https://llm.ziy.cc/v1",
      api_key="sk-你的密钥"
  )

  response = client.images.generate(
      model="Image-GI2",
      prompt="赛博朋克风格的武汉长江大桥夜景",
      size="1536x1024",
      quality="high"
  )

  print(response.data[0].url)
  ```
</CodeGroup>

<Warning>
  同步接口最长等待约 15 分钟。Image-GPT2 等长耗时模型可能耗时数分钟，建议使用[异步接口](/api-reference/image-generation/asynchronous)。
</Warning>
