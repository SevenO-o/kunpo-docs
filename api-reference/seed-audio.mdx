<span id="豆包-seed-audio-音频生成" />

使用 KUNPO 的音频生成接口创建音效、环境音或语音音频。接口同时兼容 OpenAI Audio Speech 请求参数和豆包 Seed Audio 原生参数。

## 接口地址

```
POST https://llm.ziy.cc/v1/audio/speech
```

认证方式：`Authorization: Bearer sk-你的密钥`。请求使用 `application/json`；成功时直接返回音频二进制，而非 JSON。

<Warning>
  音频生成必须调用 `/v1/audio/speech`，不要使用 `/v1/chat/completions`。
</Warning>

<Note>
  最大生成时长为 120 秒，基础价为 ¥1/分钟，另乘所用分组倍率。按生成音频的计费时长 向上取整到整秒，再将分钟数四舍五入至 0.001 分钟结算。例如 6.1 秒先计为 7 秒，再折算为 0.117 分钟；分组倍率为 1 时费用约 ¥0.117。当前时长计费规则的请求预留为零，完成后扣取实际费用，并非固定预扣 120 秒。
</Note>

## 可用模型

| 模型 | 语言 |
|------|------|
| `seed-audio-1.0` | 中文、英文 |
| `seed-audio-1.0-multilingual` | 中文、英文、日语、韩语、西班牙语、德语、法语、葡萄牙语、泰语、越南语、马来语、菲律宾语、意大利语、俄语、荷兰语、波兰语、土耳其语等 |

## 兼容性与响应

请求可使用两种参数风格：

1. OpenAI 兼容：`input`、`response_format`
2. 豆包原生：`text_prompt`、`references`、`audio_config`、`watermark`

成功响应直接返回音频文件的二进制内容，不返回时长、下载地址或字幕 JSON。保存文件后即可播放；计费时长与费用在 KUNPO 用量记录中查看。

<Warning>
  成功响应不能调用 `response.json()`。请读取二进制内容，例如 Python 的 `response.content`。请求使用非流式方式；`stream_format: "sse"` 不会开启实时音频流。
</Warning>

## 顶层请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | `seed-audio-1.0` 或 `seed-audio-1.0-multilingual` |
| `input` | string | 二选一 | OpenAI 兼容提示词，会转换为 `text_prompt` |
| `text_prompt` | string | 二选一 | 豆包原生提示词，优先级高于 `input`，最多 3000 字符 |
| `references` | object[] | 否 | 参考音频、音色或图片，详见下文 |
| `audio_config` | object | 否 | 输出格式、采样率、语速、音量、音调等 |
| `watermark` | object | 否 | 显式或隐式水印配置 |
| `response_format` | string | 否 | OpenAI 兼容输出格式；默认 `mp3` |
| `instructions` | string | 否 | 仅当 `text_prompt` 和 `input` 都为空时作为提示词 |
| `voice` | string | 否 | Seed Audio 不使用此字段；指定音色请使用 `references[].speaker` |
| `speed` | number | 否 | Seed Audio 不使用此字段；调速请使用 `audio_config.speech_rate` |

提示词优先级：

```text
text_prompt > input > instructions
```

输出格式优先级：

```text
audio_config.format > response_format > mp3
```

## `references` 参考资源

每个 `references` 元素只能选择一种资源类型。

| 参数 | 类型 | 说明 |
|------|------|------|
| `speaker` | string | 已开通且可用的豆包语音合成 2.0 / 声音复刻音色 ID |
| `audio_data` | string | 原始音频的 Base64，不要带 `data:audio/...;base64,` 前缀 |
| `audio_url` | string | 可从公网直接访问的音频 URL |
| `image_data` | string | 原始图片的 Base64，不要带 Data URI 前缀 |
| `image_url` | string | 可从公网直接访问的图片 URL |

限制与互斥关系：

- 最多 3 条参考音频；每条最长 30 秒、最大 10 MB，格式为 `wav`、`mp3`、`pcm`、`ogg_opus`。
- 最多 1 张参考图片，最大 10 MB，格式为 `jpeg`、`png`、`webp`。
- 图片参考和音频参考不能混用。
- `speaker`、`audio_data`、`audio_url` 三者互斥；`image_data`、`image_url` 二者互斥。
- 使用多条参考音频时，可在提示词中用 `@音频1`、`@音频2`、`@音频3` 按数组顺序引用。
- `speaker` 须使用当前平台可用的音色 ID；需要特定音色时请联系管理员。

<Tip>
  `references[].image_url` 使用可从公网直接访问的图片 URL；它不能与任意音频类型的参考资源同时出现。如果图片站点阻止图片下载，请改用 `image_data` 传递不带 Data URI 前缀的 Base64。
</Tip>

## `audio_config` 输出配置

| 参数 | 类型 | 默认值 | 取值 |
|------|------|--------|------|
| `format` | string | KUNPO 默认 `mp3` | `wav`、`mp3`、`pcm`、`ogg_opus` |
| `sample_rate` | int | KUNPO 默认 `48000` | `8000`、`16000`、`24000`、`32000`、`44100`、`48000` |
| `speech_rate` | int | `0` | `-50`～`100`；`-50`=0.5 倍，`100`=2.0 倍 |
| `loudness_rate` | int | `0` | `-50`～`100`；`-50`=0.5 倍，`100`=2.0 倍 |
| `pitch_rate` | int | `0` | `-12`～`12` |
| `enable_subtitle` | bool | `false` | 是否生成字级时间戳；本接口不返回字幕 JSON |

- `sample_rate` 默认值为 `48000`，请使用上表列出的采样率。
- `enable_subtitle` 不改变二进制响应格式。
- `response_format: "opus"` 会使用 `ogg_opus` 格式。
- `aac`、`flac` 不受 Seed Audio 支持，当前会降级为 `mp3`；建议只使用上表四种格式。

## `watermark` 水印配置

```json
{
  "aigc_watermark": false,
  "aigc_metadata": {
    "enable": false,
    "content_producer": "",
    "produce_id": "",
    "content_propagator": "",
    "propagate_id": ""
  }
}
```

- `aigc_watermark`：是否在音频结尾增加显式节奏标识，默认 `false`。
- `aigc_metadata.enable`：是否在音频 Header 写入隐式水印元数据，默认 `false`。
- 其余字段分别为内容生产者、制作编号、传播者和传播编号。

<CodeGroup>
  ```bash cURL
  curl https://llm.ziy.cc/v1/audio/speech \
    -H "Authorization: Bearer sk-你的密钥" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "seed-audio-1.0-multilingual",
      "input": "生成十秒钟轻柔雨声，无人声",
      "response_format": "mp3"
    }' \
    --output rain.mp3
  ```

  ```python Python
  from pathlib import Path

  import requests

  response = requests.post(
      "https://llm.ziy.cc/v1/audio/speech",
      headers={"Authorization": "Bearer sk-你的密钥"},
      json={
          "model": "seed-audio-1.0-multilingual",
          "input": "生成十秒钟轻柔雨声，无人声",
          "response_format": "mp3",
      },
      timeout=180,
  )
  response.raise_for_status()
  Path("rain.mp3").write_bytes(response.content)
  ```

  ```python OpenAI SDK
  from openai import OpenAI

  client = OpenAI(
      base_url="https://llm.ziy.cc/v1",
      api_key="sk-你的密钥",
  )

  audio = client.audio.speech.create(
      model="seed-audio-1.0-multilingual",
      voice="alloy",  # OpenAI SDK 要求传入；Seed Audio 会忽略
      input="生成十秒钟轻柔雨声，无人声",
      response_format="mp3",
  )
  audio.write_to_file("rain.mp3")
  ```

## 使用参考资源

### 参考音频（Base64）

```python
import base64
import requests

with open("reference.wav", "rb") as f:
    audio_base64 = base64.b64encode(f.read()).decode()

response = requests.post(
    "https://llm.ziy.cc/v1/audio/speech",
    headers={"Authorization": "Bearer sk-你的密钥"},
    json={
        "model": "seed-audio-1.0",
        "text_prompt": "参考@音频1的音色，生成五秒钟舒缓环境音乐",
        "references": [{"audio_data": audio_base64}],
        "audio_config": {"format": "mp3", "sample_rate": 48000},
    },
    timeout=180,
)
response.raise_for_status()

with open("result.mp3", "wb") as f:
    f.write(response.content)
```

## 成功与失败响应

成功时直接返回音频：

```http
HTTP/2 200
Content-Type: audio/mpeg
```

| `format` | Content-Type |
|----------|--------------|
| `mp3` | `audio/mpeg` |
| `wav` | `audio/wav` |
| `pcm` | `audio/pcm` |
| `ogg_opus` / `opus` | `audio/ogg` |

失败时返回 KUNPO 标准 JSON：

```json
{
  "error": {
    "message": "错误详情",
    "type": "bad_response_status_code",
    "param": "",
    "code": "bad_response_status_code"
  }
}
```

| 状态码 | 含义 |
|:------:|------|
| `400` | 参数、参考资源、音色 ID 或请求错误 |
| `401` | API Key 无效 |
| `403` | 用户分组或模型权限不足 |
| `429` | 余额、额度或请求限流 |
| `502` | 服务响应、音频下载或格式异常 |
