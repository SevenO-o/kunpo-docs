## 支持模型

点击模型名称查看完整用法。请求中的 `model` 必须使用 **API 调用名**，不能用产品展示名代替。

| 模型 | API 调用名 | 文生图 | 图生图 | 同步 | 异步 | 推荐方式 |
|------|------------|:------:|:------:|:----:|:----:|----------|
| [Nano Banana Pro](/api-reference/image-generation/models/nano-banana-pro) | `Image-GI` | 支持 | 支持 | 支持 | 支持 | 同步 |
| [Nano Banana 2](/api-reference/image-generation/models/nano-banana-2) | `Image-GI2` | 支持 | 支持 | 支持 | 支持 | 同步 |
| [GPT Image 2](/api-reference/image-generation/models/gpt-image-2) | `Image-GPT2` | 支持 | 支持 | 支持 | 支持 | 异步 |
| [Qwen Image 3.0 Pro](/api-reference/image-generation/models/qwen-image-3-pro) | `qwen-image-3.0-pro` | 支持 | 多模态输入 | 支持 | 不支持 | 同步 |
| [Seedream 5.0 Pro](/api-reference/image-generation/models/image-si) | `Image-SI` | 支持 | 支持 | 支持 | 不支持 | 同步 |
| [Midjourney](/api-reference/image-generation/models/midjourney) | `Image-MI` | 支持 | 不支持 | 支持 | 支持 | 同步 |

### 选择建议

日常出图可从 Nano Banana 2 开始；复杂图文排版、中文小字和界面素材可查看 [Qwen Image 3.0 Pro](/api-reference/image-generation/models/qwen-image-3-pro)；高质量精细出图可查看 [GPT Image 2](/api-reference/image-generation/models/gpt-image-2)。具体耗时、输入格式与限制以各模型页说明为准。

## 计费说明

以下五款模型为**固定按次计费**，每次请求固定扣费，与输出分辨率无关。Seedream 5.0 Pro 为动态计费，不适用这一规则。

| 模型 | 单价（美元/次） | 约合人民币 | 计费方式 |
|------|:-------------:|:----------:|----------|
| `Image-GI` | $0.18 | ≈ ¥1.3 | 固定按次 |
| `Image-GI2` | $0.09 | ≈ ¥0.65 | 固定按次 |
| `Image-GPT2` | $0.05 | ≈ ¥0.36 | 固定按次 |
| `Image-MI` | $0.069 | ≈ ¥0.5 | 固定按次（一次 4 张） |
| `qwen-image-3.0-pro` | $0.069 | ≈ ¥0.5 | 固定按次 |

Seedream 5.0 Pro 的动态计费请以[模型广场](https://llm.ziy.cc/pricing)和实际调用账单为准，不能将某次测试扣费当作固定单价。

<Tip>
  以上价格仅供参考，实际计费请以控制台模型市场中的实时价格为准。
</Tip>

## 认证

所有图片请求使用以下请求头。获取密钥见[快速开始](/quick-start)。

```text
Authorization: Bearer sk-你的密钥
```

## 图片存储

生成的图片自动转存至 KUNPO 图床（COS），返回永久 CDN 链接（`https://kunpoapiimg.ziy.cc/...`），不受上游临时 URL 过期限制。
